# Qeen.AI

> Qeen (qeen.ai) is a Dubai-based AI company for GCC and wider MENA e-commerce, founded in 2023 by
> former Google and DeepMind researchers and backed by a $10M seed led by Prosus Ventures ($12M
> total). It sells two things: a self-serve content-optimization app that generates, localizes and
> A/B-tests Arabic and English product content, and a commission-based growth marketing engagement.
> Qeen publishes no OpenAPI, no developer portal and no public API documentation. Its machine
> surface is three first-party client SDKs — iOS, Android and browser — whose credentials are
> issued privately.

This file was generated by API Evangelist from publicly fetched Qeen artifacts on 2026-08-12.
Qeen does not publish an llms.txt of its own; /llms.txt returns 404 on qeen.ai.

## Client SDKs

- [Qeen Mobile Analytics SDK for iOS](https://github.com/fodoole/qeen-mobile-sdk-ios): Swift
  package, binary XCFramework, v1.5.0 (2026-08-12). `import Qeen`; namespace `QeenSDK`. iOS 15+.
  Public API: configure(apiKey:host:debug:options:), identify(userId:traits:), track(_:properties:),
  track(QeenEvent), productViewed, addToCart, cartUpdated, couponApplied, couponRemoved,
  cartCleared, paymentMethodSet, shippingDetailsSet, checkoutStarted, orderCompleted, orderPlaced,
  orderRefunded, signedIn, signedUp, screen(_:properties:), reset(), flush(), handleDeepLink(_:).
- [Qeen Android SDK](https://github.com/fodoole/qeen-maven): `ai.qeen:qeensdk:1.5.0` from the
  self-hosted Maven repo https://raw.githubusercontent.com/fodoole/qeen-maven/main — not Maven Central.
- [qeen.js browser SDK](https://cdn.qeen.ai/sdk/qeen.js): script tag, `window.qeen`, sdkVersion 1.0.
  Methods: fetchQeenContent, initPageSession, bindClickEvents, bindScrollEvents, sendCheckoutEvent,
  setContentServed, resetContentServed, sendContentServedEvent.
- [qeen loader snippet](https://cdn.qeen.ai/loader/main.js): tag-manager-style bootstrap.
- [qeenSearch widget](https://cdn.qeen.ai/sdk/v1.0/qeenSearch.js): embedded AI storefront search.

## Authentication

- API key plus a customer-provisioned `host`, passed to `QeenSDK.configure`. Neither is self-serve —
  both SDK READMEs state they are "shared privately by email — contact tech@qeen.ai".
- The customer platform API at https://users.qeen.ai/api/v1/ is a Django REST Framework service
  behind cookie session auth. Unauthenticated requests return
  `{"detail":"Authentication credentials were not provided."}`. It is the web app's own backend,
  not a developer API.
- No OAuth, no OpenID Connect, no scopes, no mTLS, no key self-service.

## What is NOT published

An agent should not go looking for these — each was probed on 2026-08-12 and does not exist:

- No OpenAPI, Swagger, GraphQL or AsyncAPI specification on any host.
- No MCP server. No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json.
- No document at any /.well-known/ path, including security.txt.
- No developer portal, API reference, quickstart, changelog page, status page, SLA, deprecation
  policy, rate-limit documentation, sandbox, CLI or Postman collection.
- No published rate limits and no rate-limit response headers.
- Note: app.qeen.ai and blog.qeen.ai answer HTTP 200 with an HTML shell for *every* path. A 200
  from those hosts is not a document.
